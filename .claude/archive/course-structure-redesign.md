> 创建：2026-04-28

> 背景：基于头脑风暴讨论 + 国内高校AI课程调研（2024-2026）

---

## 一、重构动因

当前数据模型课程结构只有两层（Course → Unit），存在三个核心问题：

1. **没有阶段概念**：单元平铺，学生看不出学习节奏
2. **三类课程孤立**：通识/专业/项目三条独立跑道，无路径引导
3. **行业方向无落脚点**：项目课按行业细分，数据模型无法承载

---

## 二、平台定位（已确认）

**第一期聚焦高职院校**，本科课程后续迭代。

高职与本科培养逻辑的核心差异：

| 维度 | 本科 | 高职 |
|------|------|------|
| 培养目标 | 理解原理，能研究、能深造 | 会用工具，能上岗、能操作 |
| 课程逻辑 | 知识体系逻辑（学科本位） | 职业工作过程逻辑（岗位本位） |
| 实践比例 | 30-40% | ≥50%（国标硬性要求） |
| 行业对接 | AI+X 交叉微专业 | 岗课赛证融通，直接对岗 |

## 三、新数据模型：三层结构

### 层级关系

```
EduPath（学习路径）         ← 新增，用户在课程列表看到的顶层单位
  └── EduCourse（课程）     ← 重新定位，每门独立可学的课
        └── EduUnit（单元） ← 课程内的章节，含右侧面板配置
```

**核心变化**：原 `EduCourse` 升级为 `EduPath`，原 `EduUnit` 提升为 `EduCourse`，新增 `EduUnit` 作为课程内细分章节（第一期每门课可只有1个单元）。

### EduPath 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int PK | 自增主键 |
| title | str | 路径名称，如"AI通识路径" |
| type | enum | general / professional / project |
| industry | str \| null | 仅 project 类型填写：logistics / ecommerce / medical / ... |
| description | str \| null | 路径简介 |
| cover | str \| null | 封面图 URL |
| school_type | str | vocational（高职）/ undergraduate（本科），默认 vocational |
| order | int | 展示顺序 |
| status | int | 0=启用 / 1=禁用 |
| create_time | datetime | |

### EduCourse 表（重新定位）

| 字段 | 类型 | 说明 |

## 四、高职课程体系（已确认）

### 体系全景

```
E-Agent 高职智能体教学平台
│
├── 路径一：AI通识路径          ← 认知与工具使用（面向全体高职学生）
│
├── 路径二：AI专业核心路径      ← 技术能力建设（面向AI/计算机专业）
│
└── 路径三：项目实操路径        ← 行业场景落地（面向各专业）
      ├── 物流方向（8门）
      ├── 电商方向（8门）
      └── 更多行业（后续扩充）
```

### 数量汇总

| 路径 | 面向学生 | 课程数 | 学时 |
|------|---------|--------|------|
| AI通识路径 | 全体高职学生 | 6门 | 12学时 |
| AI专业核心路径 | AI/计算机专业 | 7门 | 36学时 |
| 项目实操路径·物流 | 物流/供应链专业 | 8门 | 32学时 |
| 项目实操路径·电商 | 电商/市场营销专业 | 8门 | 32学时 |
| **合计** | | **29门课程** | **112学时** |

### 路径一：AI通识路径

**受众**：全体高职学生，零基础
**目标**：用AI工具完成岗位日常任务
**学时**：12学时 / 6门课程
**对应国标**：AI应用导论（公共基础课）

## 五、前端路由影响

现有路由结构需调整，新增路径层级：

| 路由 | 功能 |
|------|------|
| `/education/courses` | 路径列表页（展示4条路径卡片） |
| `/education/paths/:pathId` | 路径详情页（展示该路径下所有课程，按阶段分组） |
| `/education/paths/:pathId/courses/:courseId` | 课程学习页（双栏：左栏图文 + 右栏操作面板） |
| `/education/paths/:pathId/courses/:courseId/:unitId` | 单元章节页（第一期每门课只有1个单元，可省略此层） |
